# CCBox 0.1.8 源码更新

此版本整合上游 0.1.8 的客户端改进。发布安装包前仍需按 CCBox 发布流程构建和验收。

- Windows 客机浏览器按查看端像素密度渲染。原生画面、空闲轮询、内存回收和会话刷新有所优化。
- 通用设置支持 12 / 24 小时制。项目可绑定多个文件夹，账户恢复与登录流程有更新。
- Linux 客机基础软件包安装失败时显示失败命令、软件包和脱敏日志。Windows 客机的手动 ISO 安装修复应答文件识别。
- 更新 macOS 网卡筛选、IPv6 检查、文件权限恢复和屏幕共享，集成 Windows SSH 远程环境支持。Intel Mac 构建依然属于实验功能。
- 首次安装 Linux 客机前沿用 CCBox 的虚拟化预检。客户端授权和激活码后台继续沿用 CCBox 的实现。
- 安装包继续通过 CCBox 官网发放。桌面端按 CCBox 的手动更新流程操作。
